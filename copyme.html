Formatting & shortcuts

Markdown

# / ## / ###Headings (also populate the TOC on the left)
**bold**Bold
*italic*Italic (no _underscore_ form — avoids breaking snake_case names)
~~strike~~Strikethrough
++underline++Underline (not standard Markdown, but _underscore_ was ruled out for the same identifier-collision reason)
`code`Inline code — safe for function/variable names, e.g. verify_implement()
- item / 1. itemBulleted / numbered list
> textBlockquote
[text](url)Link
![alt](path)Image — path is relative to the doc's folder, e.g. an images/ subfolder you create yourself
[text][1] or [1]
[1]: url		Reference-style link — cite as [1] anywhere in the paragraph, define [1]: url on its own line; renders as a small numbered reference list at the bottom of that paragraph

Markdown works the same way in comments as in paragraphs.

Editing

Click a paragraphEnter edit mode (shows raw markdown)
EnterSave and exit edit mode
Shift+EnterLine break within the same paragraph
EscapeDiscard changes and exit edit mode
Hover between paragraphsA + appears to insert a new paragraph there
Click empty space below the docOpens the "add paragraph at the end" spot
🗑 in a paragraph's metadata lineDelete that paragraph (and its comments) after a confirmation — there's no undo

Comments & discussion

💬 icon on a paragraphStart or view its comment thread, in the right-hand column
Click a comment cardJumps back to (and highlights) the paragraph it's attached to
resolve / reopenCollapses a thread once it's settled; resolved threads stop me from reacting further

Theming

Edit theme.css in this folder directly — it's linked as a normal stylesheet and starts out as a live copy of the default colors (--bg, --fg, --muted, --border, --accent, --hover-bg, --hover-bg-strong, --pending, --pending-edit, --resolved, --danger, plus a dark-mode block). Change any value and reload the page to see it. Shared across every doc you make from copyme.html, since they all link the same relative theme.css.
